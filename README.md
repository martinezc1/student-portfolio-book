# Reproducible Research in Practice

## About

**Reproducible Research in Practice** is a collection of student portfolio
books developed as part of a graduate course in **Reproducible Research
using R** at Brooklyn College.

Throughout the course, students completed a sequence of assignments using
R and Quarto. Rather than treating these assignments as "one-and-done"
submissions, students progressively revised and assembled their work into
individual Quarto portfolio books.

This repository brings those individual portfolios together into a single
meta-book. Each chapter introduces a student and provides access to their
complete portfolio.

## View the Published Book

The complete collection is published online through Posit Connect Cloud:

<https://martinezc1-reproducible-research-using-r--student-work-in-pract.share.connect.posit.cloud/>

## Portfolio Structure

All students completed the same general sequence of assignments, including
work involving:

- data import and cleaning;
- data transformation and exploration;
- statistical analysis, including t-tests, ANOVA, and regression;
- data visualization; and
- reproducible reporting using Quarto.

While students worked within a shared structure, each portfolio reflects
the student's individual analytical decisions, visualizations, explanations,
and approach to communicating results.

## Teaching Ecosystem

This collection is part of a broader ecosystem of open and reproducible
teaching materials:

1. **Reproducible Research Using R** — introduces the concepts and technical
   foundations used throughout the course.
2. **Teaching Reproducible Research Using R** — provides the teaching
   structure, assignments, and workflows used to implement the course.
3. **Reproducible Research in Practice** — this collection, bringing together
   the student portfolio books developed from those assignments.
4. **NYC Open Data Student Gallery** — showcases students' independent
   research projects developed using the skills built throughout the course.

Together, these resources create a pathway from learning foundational
concepts to producing reproducible, public-facing analytical work.

## The Portfolio Approach

The portfolio structure used in this course is based on a simple principle:
coursework does not need to disappear after it is graded.

Assignments are progressively revised, connected, and transformed into
larger bodies of work that document students' analytical development over
time.

The structure of the portfolio assignment is described in **Chapter 13 of
Teaching Reproducible Research Using R**.

This approach also helped inform the broader **Accidental Author** framework,
which focuses on transforming existing coursework into cumulative,
public-facing student portfolios.

## Repository Structure

This repository contains the files used to build the collective Quarto book,
including the introductory material and individual chapters representing
each student's portfolio.

The complete student portfolio books are maintained as individual works and
linked from their corresponding chapters in the published collection.
